01Personal AI agent · Windows + Android

JAS, my own JARVIS

A voice-first AI companion that lives on my laptop. Say "Jarvis", ask for something, and it actually does it: opens apps, drives the browser, reads the screen, sets reminders and handles Google tasks.

  • Wake word runs fully on-device; speech to text runs on the laptop's Intel GPU with Whisper + OpenVINO
  • LLM agent with tool calling, risk levels and confirmation for anything risky, enforced in code, not in the prompt
  • Browser control with Playwright, vision-guided mouse clicks, long-term memory, reminders, Calendar, Gmail and Drive
  • Native Android companion app with a pinned certificate, reachable from outside the house over Tailscale
  • 200+ automated tests plus manual hardware test scripts

02Fintech · Open banking

Account Aggregator

A consent-first pipeline on India's RBI Account Aggregator framework. The user approves exactly what to share and for how long; their financial data then flows securely from banks and institutions into a clear picture of their finances.

  • Consent request → approval → encrypted data fetch from Financial Information Providers (FIPs)
  • Decrypts, validates and normalises statements from different sources into one schema
  • Turns raw transactions into insights: income, spending categories, balances over time

03Productivity · LLM + spreadsheets

Excel for non-Excel users

Most people know what they want from their data but not the formula to get it. Type the question in plain English and the assistant writes the formula, pivot or chart, and explains what it did.

  • Natural language to formulas, filters, pivots and charts
  • Reads the sheet's real headers and types before generating anything, so answers fit the data
  • Shows the formula it used, so users learn instead of trusting a black box

04HR tech · Voice AI

Virtual AI Interviewer

A voice-based interviewer that runs a real conversation: it asks role-specific questions, listens, asks follow-ups based on what the candidate said, and produces a structured scorecard.

  • Speech in, speech out, with turn-taking so it doesn't talk over the candidate
  • Adaptive follow-up questions generated from the candidate's own answers
  • Rubric-based scoring with evidence quotes, so recruiters can see why a score was given

05Automation · Agentic AI

AI Agents Lab

A set of task-focused agents that plan, call tools and hand work to each other through an orchestrator. Each agent does one job well, and every step is logged so a person can check it.

  • Research agent: searches, reads sources and writes a cited summary
  • Inbox triage agent: sorts mail by urgency and drafts replies for approval
  • Document extractor: pulls structured fields out of invoices and PDFs
  • Data analyst agent: answers questions over a database with SQL and charts
